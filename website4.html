API

Powerful API

Integrate cutting-edge AI into your applications with our simple, fast, and reliable API.

POST /v1/chat/completions

Send messages and receive AI-generated responses with support for multi-turn conversations.

curl -X POST https://api.nexusai.com/v1/chat/completions
-H "Authorization: Bearer nx-..."
-H "Content-Type: application/json"
-d '{
"model": "nexus-4-turbo",
"messages": [{"role": "user", "content": "Hello!"}]
}'
POST /v1/images/generations

Generate images from text prompts with DALL·E quality output and customizable dimensions.

curl -X POST https://api.nexusai.com/v1/images/generations
-H "Authorization: Bearer nx-..."
-d '{"prompt": "A sunset over mountains", "size": "1024x1024"}'
GET /v1/models

List all available models with their capabilities, pricing, and context windows.

POST /v1/embeddings

Generate vector embeddings for text, enabling semantic search, clustering, and classification.
